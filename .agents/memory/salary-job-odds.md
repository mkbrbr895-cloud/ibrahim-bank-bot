name: Salary job odds
description: Decision on how the salary feature interprets the requested job percentages.
---

Treat the listed job values 80/50/40/10 as relative weights and normalize them for a single exclusive job draw.

**Why:** The user chose this interpretation because the listed percentages total 180%, while each salary claim must select exactly one job.

**How to apply:** Keep the relative weighting intact unless the user provides a different distribution or changes the salary rules.
