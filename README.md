# بوت مؤقت تيليجرام

بوت بسيط ينشئ عدادًا تنازليًا في المجموعات، ويثبّت رسالة العداد ويحدّثها كل 10 ثوانٍ.

## التشغيل

1. ألغِ رمز البوت الذي أُرسل في المحادثة وأنشئ رمزًا جديدًا عبر BotFather.
2. احفظ الرمز الجديد في أسرار Replit بالاسم `TELEGRAM_BOT_TOKEN`.
3. أضف البوت إلى المجموعة وامنحه صلاحية تثبيت الرسائل.
4. شغّل المشروع.

استخدم الأمر بهذا الشكل:

`/timer 5 استراحة`

المدة من دقيقة واحدة إلى 7 أيام، ويجب استخدام الأمر داخل مجموعة أو مجموعة فائقة.
