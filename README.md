# بوت إبراهيم للمجموعات

بوت تيليجرام للمؤقت والترحيب والإشراف، مع لعبة تخمين أعلام ونظام نقاط محفوظ محليًا.

## الأوامر والميزات

- `/timer 5 استراحة` — يبدأ مؤقتًا ويثبّت رسالته ويحدّثها كل 10 ثوانٍ.
- عند انضمام عضو جديد، يرسل البوت رسالة الترحيب وقوانين المجموعة.
- ردّ على رسالة عضو واكتب `كتم` أو `/mute` — كتم لمدة 60 ثانية للمشرفين فقط. لا يمكن كتم صانع البوت `@Ibrahimroblox14GRM`.
- `/علم` أو كتابة `تخمين` — يبدأ لعبة أعلام؛ أول إجابة صحيحة تحصل على 50 نقطة.
- `/حسابي` أو `/بنك` — ينشئ حساب نقاط ويرسل صورة بطاقة افتراضية.
- ردّ على رسالة عضو واكتب `/تحويل <المبلغ>`، أو اكتب `/تحويل <المبلغ> <رقم البطاقة>`.

تُخصم عمولة 10 نقاط عن كل تحويل وتُضاف إلى حساب صانع البوت. يجب أن يغطي الرصيد مبلغ التحويل والعمولة معًا. البطاقات افتراضية للعبة فقط وليست وسيلة دفع حقيقية.

تُحفظ الحسابات والنقاط وأرقام البطاقات في `data/bot.sqlite3` وتبقى محفوظة عند إعادة تشغيل البوت. لعبة الأعلام والكتم يتطلبان مجموعة فائقة؛ يحتاج البوت صلاحية تثبيت الرسائل وتقييد الأعضاء لتنفيذ إجراءات الإشراف.

## التشغيل

أضف رمز البوت إلى أسرار Replit باسم `TELEGRAM_BOT_TOKEN`، ثم شغّل سير عمل `Run Python project`.
