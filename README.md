# بوت إبراهيم للمجموعات

بوت تيليجرام للمجموعات يركز على لعبة تخمين الأعلام ونظام البنك والراتب، مع حفظ النقاط محليًا.

## الأوامر والميزات

- `اعلام` أو `أعلام` — يبدأ لعبة أعلام؛ أول إجابة صحيحة تحصل على 50 نقطة.
- `حسابي` أو `بنك` أو `/حسابي` أو `/بنك` — ينشئ حساب نقاط ويرسل صورة بطاقة افتراضية.
- `راتب` أو `/راتب` — يستلم راتب وظيفة عشوائية وبخشيش مرة كل ساعة.
- ردّ على رسالة عضو واكتب `تحويل <المبلغ>`، أو اكتب `/تحويل <المبلغ> <رقم البطاقة>`.

تُخصم عمولة 10 نقاط عن كل تحويل وتُضاف إلى حساب صانع البوت. يجب أن يغطي الرصيد مبلغ التحويل والعمولة معًا. البطاقات افتراضية للعبة فقط وليست وسيلة دفع حقيقية.

يُضاف الراتب والبخشيش إلى رصيد الحساب مباشرةً. تُحفظ الحسابات والنقاط وأرقام البطاقات ومواعيد استلام الرواتب في `data/bot.sqlite3` وتبقى محفوظة عند إعادة تشغيل البوت.

## التشغيل

أضف رمز البوت إلى أسرار Replit باسم `TELEGRAM_BOT_TOKEN`، ثم شغّل سير عمل `Run Python project`.
